# 绝区零 Wiki 插件（MaiBot）

基于 MaiBot SDK v2 的绝区零 BWIKI 查询插件，实时抓取数据，不维护本地数据库。支持角色、音擎、驱动盘、邦布的属性、技能、养成、配装、影画、词条、语音台词与立绘大图查询，命令结果以中文图片卡片返回（可配置回退为纯文本）。

## 功能

- 角色 / 音擎 / 驱动盘 / 邦布 属性查询
- 技能、养成、配装、影画、词条、语音台词
- 立绘大图（返回原图，附来源与版权提示）
- 缺失词条给出候选建议，不自动挑选相似人物
- 内置别名（鲨鱼妹 → 艾莲 等），支持自定义别名
- 页面缓存 + 过期标记 + 容量上限
- 同时提供 LLM 工具 `zzz_wiki_query`，供麦麦按需调用

## 环境要求

- MaiBot 主程序 `0.10.0+`
- MaiBot SDK `2.6.0+`
- Python `3.10+`
- 依赖：`httpx`、`beautifulsoup4`、`Pillow`（manifest 声明，宿主可自动安装）

## 安装

1. 把本仓库（或 Release 源码包）放入 MaiBot 的 `plugins/` 目录，确保 `_manifest.json`、`plugin.py`、`zzz_wiki/`、`assets/` 都在插件文件夹内。
2. 重载插件。首次加载由 Runner 生成 `config.toml`，默认配置即可用。
3. 也可从麦麦插件市场安装（审核通过后）。

> 手动安装时请直接解压，不要使用会转码中文文件名的安装方式。

## 指令

| 指令 | 结果 |
|---|---|
| `zzz 艾莲` | 角色属性 |
| `zzz 艾莲 技能` | 技能详情 |
| `zzz 艾莲 养成` | 晋阶材料 |
| `zzz 艾莲 配装` | 配装推荐 |
| `zzz 艾莲 影画` | 意象影画 |
| `zzz 艾莲 词条` | 词条推荐 |
| `zzz 艾莲 语音` | 语音台词文字 |
| `zzz 艾莲 大图` | 立绘原图 |
| `zzz 深海访客` | 音擎 |
| `zzz 啄木鸟电音` | 驱动盘 |
| `zzz 搜索 关键词` | 候选词条 |
| `zzz clear` | 清缓存（仅 `admin_users`） |

支持无空格写法（如 `zzz艾莲技能`），也可用 `绝区零 艾莲`。指令与碧蓝航线 `wiki`、萌娘百科等插件互不冲突。

## 配置

在麦麦插件配置页（或 `config.toml` 的 `[plugin]` 段）可设置：

| 字段 | 默认 | 说明 |
|---|---|---|
| `image_reply` | `true` | 图片卡片回复，失败回退文本 |
| `request_timeout` | `15.0` | 请求超时（秒），范围 1–60 |
| `cache_ttl` | `3600` | 页面缓存秒数 |
| `max_cache_mb` | `100` | 页面缓存上限 MB |
| `max_text_chars` | `5000` | 文本/模型工具内容长度上限 |
| `max_card_chars` | `1800` | 卡片文字长度上限 |
| `font_path` | `""` | 自定义中文字体路径，留空用随包字体 |
| `admin_users` | `[]` | 可执行 `zzz clear` 的平台用户 ID |
| `aliases` | `{}` | 自定义别名映射 |

参数热更新在保存配置后自动生效。

## 已知限制

- 技能、配装、表格内容较长时会截断，完整内容请打开返回的来源链接。
- BWIKI 改版可能导致解析失效，需跟进选择器。
- 页面无对应章节时明确报缺失，不假装取到数据。
