绝区零 Wiki 插件 v0.1.0（首版，待实际MaiBot联调）

参考： https://github.com/senhan1337/MaiBot-blhx-wiki
源码协议：AGPL-3.0；游戏图片/内容版权另见来源页面；Noto字体为SIL OFL。

安装
1. 需要 MaiBot 0.10.0+、MaiBot SDK 2.6.0+、Python 3.10+。
   本机使用官方SDK 2.19.0验证入口；最低版本依据官方ctx.paths引入版本。
2. 解压后把完整 MaiBot-zzz-wiki 文件夹放入 MaiBot 的 plugins/。
   plugin.py、_manifest.json、zzz_wiki/、assets/ 应在该文件夹内。
3. 依赖由manifest声明：httpx、beautifulsoup4、Pillow。
   若宿主未自动安装，在MaiBot自己的Python环境执行：
   python -m pip install -r plugins/MaiBot-zzz-wiki/requirements.txt
4. 使用MaiBot的插件重载功能加载；首次由Runner生成config.toml。
5. 发 zzz 看帮助，发 zzz 艾莲 验证查询。

指令
zzz 艾莲
zzz 艾莲 技能
zzz 艾莲 养成
zzz 艾莲 配装
zzz 艾莲 影画
zzz 艾莲 词条
zzz 艾莲 语音
zzz 艾莲 大图
zzz 深海访客
zzz 搜索 关键词
zzz clear（仅admin_users配置内的用户可用）
支持无空格后缀；不注册通用wiki命令，可与碧蓝航线插件并存。
语音查询返回中文台词文字，不发送音频。
模型工具 zzz_wiki_query 返回内容和来源链接；模型是否调用取决于宿主。
同名角色/形态请使用BWIKI准确标题，缺失词条返回候选，不自动选择相似人物。

配置（config.toml由Runner维护；建议WebUI修改）
[plugin]中可设置：
image_reply=true：图片卡片；失败回退文字。
request_timeout=15.0：请求超时；有效范围1至60秒。
cache_ttl=3600：页面缓存秒数。
max_cache_mb=100：页面缓存上限MB；0不缓存。
max_text_chars=5000：文本和模型工具内容长度上限。
max_card_chars=1800：图片卡片字数上限。
font_path=""：留空使用随包Noto中文字体，亦可指定系统字体绝对路径。
admin_users=[]：管理员平台用户ID；空列表则任何人都不能清理。
aliases={}：自定义别名到BWIKI准确词条名的映射；覆盖内置同名别名。
参数热更新在on_config_update中应用，避免手动修改config_version。
缓存仅保存于宿主授予的runtime_dir/zzz-pages，不随源码分发。
